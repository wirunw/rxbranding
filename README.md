# Let's Build a Brand! (rxbranding)

เว็บ workshop สร้างแบรนด์ผลิตภัณฑ์สมุนไพร จากหัวข้อ **From Lab to Launch** โดย ดร.ภก.วิรุณ เวชศิริ คณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์

ทีมนักศึกษาทำงานไล่ไปทีละรอบ ในแต่ละรอบให้ AI ช่วยคิดผ่าน prompt ที่เว็บเตรียมไว้ แล้วช่วยกันพิจารณาคำตอบก่อนเขียนข้อสรุปของทีม เมื่อทำครบ เว็บจะรวมทุกอย่างเป็นสไลด์แผนธุรกิจ 13 หน้า พร้อมภาคผนวก

- 6 รอบในคาบ: ปัญหาและลูกค้า · กลุ่มเป้าหมายและจุดยืน · ตัวตนแบรนด์ · โมเดลธุรกิจ (BMC) · การตลาดและช่องทาง · ประมาณการการเงิน
- รอบที่ 7 ทำต่อหลังคาบ: ขนาดตลาด (TAM, SAM, SOM) · เงินทุนที่ขอ · ทีม · หลักฐานจากลูกค้า
- นำเสนอแบบเต็มจอ และส่งออกเป็น PowerPoint (แก้ต่อได้) หรือ PDF

## การใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร หรือจะเปิดผ่าน GitHub Pages ก็ได้

ข้อมูลที่กรอกเก็บไว้ในเบราว์เซอร์เครื่องที่ใช้เท่านั้น ก่อนเลิกใช้งานให้กด “ส่งออกเป็น PowerPoint” ในแท็บสไลด์ของทีม แล้วเก็บไฟล์ไว้แก้ต่อ

ตัวอย่างแบรนด์ “ปลุกใจ” และตัวเลขทั้งหมดในตัวอย่างเป็นข้อมูลสมมติเพื่อการสอน
